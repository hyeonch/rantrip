# 🚇 랜덤 지하철 여행 웹앱 기획서

## 개요

여자친구와 함께하는 랜덤 지하철 여행을 위한 PWA 웹앱.
출발역을 입력하면 랜덤으로 목적지를 뽑아주는 심플한 앱.

---

## 핵심 기능 (MVP)

- 출발역 입력
- 랜덤 호선 뽑기
- 랜덤 방향 뽑기 (상행 / 하행)
- 랜덤 목적지 뽑기
- 각 단계를 순차적으로 보여주는 UI

> 여행지 추천, 맛집 정보 등 부가 기능은 포함하지 않음

---

## 랜덤 뽑기 로직 흐름

```
1. 출발역 입력 (사용자 직접 입력)
        ↓
2. 호선 랜덤 뽑기 (1~9호선 중 랜덤)
        ↓
3. 출발역 ↔ 뽑힌 호선 매칭 확인
   - 출발역이 해당 호선에 있음 → 그대로 진행
   - 출발역이 해당 호선에 없음 → 해당 호선에서 가장 가까운 역으로 출발역 대체
        ↓
4. 방향 랜덤 뽑기 (상행 / 하행)
        ↓
5. 해당 방향의 역 목록 중 랜덤 1개 뽑기 → 최종 목적지 결정
```

### 가장 가까운 역 계산 방식
- 좌표(위경도) 기준 직선거리 계산 방식 채택 예정
- 구체적인 알고리즘은 개발 단계에서 확정

---

## 기술 스택

| 항목 | 선택 | 이유 |
|------|------|------|
| 프레임워크 | React + Vite | 단계별 상태관리 용이, 익숙한 웹 개발 환경 |
| 스타일 | 미정 (TailwindCSS 등) | 가볍게 구성 |
| 백엔드 | 없음 | 서버 필요 기능 없음 |
| 배포 | GitHub Pages 또는 Netlify | 무료 정적 호스팅 |
| 앱 형태 | PWA | 모바일 홈 화면 설치 가능 |

### PWA 설치 방법
- **iOS**: 사파리 → 공유 버튼 → 홈 화면에 추가
- **Android**: 크롬 → 앱 설치 배너 또는 메뉴에서 설치

## 데이터 계획

### 필요한 데이터
- 역 이름
- 호선 정보
- 호선 내 역 순서 (상/하행 방향 계산용)
- 역 좌표 (위경도, 가장 가까운 역 계산용)

### 데이터 수급 전략
1. **공공데이터포털(data.go.kr) / 서울 열린데이터광장**에서 공식 CSV 다운로드
2. AI로 JSON 초안 생성 후 공공데이터로 검증 및 보완
3. 최종 가공된 JSON 파일을 앱에 번들로 포함

### 데이터 용량 예상
- 1~9호선 전체 역 수: 약 300~350개
- JSON 변환 시 예상 크기: **약 50~100KB**
- 이미지 한 장보다 작아 배포 부담 없음

### 데이터 형태 (예시)
```json
{
  "stations": [
    {
      "name": "강남",
      "lines": [2],
      "lat": 37.4979,
      "lng": 127.0276,
      "lineOrder": {
        "2": 220
      }
    },
    {
      "name": "동대문역사문화공원",
      "lines": [2, 4, 5],
      "lat": 37.5650,
      "lng": 127.0095,
      "lineOrder": {
        "2": 205,
        "4": 410,
        "5": 543
      }
    }
  ]
}
```
